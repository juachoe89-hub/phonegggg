# Character Phone

설치 없이 실행 가능한 가상 스마트폰 프로토타입입니다.

## 실행
`index.html` 파일을 브라우저에서 열면 됩니다. GitHub Pages로 배포할 때도 저장소 루트에 `index.html`을 올리면 됩니다.

## 테스트 패턴
1 → 2 → 3 → 6 → 9 (윗줄을 오른쪽으로, 오른쪽 열을 아래로 긋는 ㄱ자)

## 포함 기능
- 잠금 화면과 패턴 입력
- 홈 화면 및 뒤로 가기/홈/최근 앱
- 인터넷(가상), 캘린더, 메모, 시계, 갤러리, 음악, 전화, 연락처, 메시지
- 메시지 분기 대본: 키워드에 따라 미리 준비한 답장 선택
- 새로고침 시 데이터 초기화

## 한계
- 실제 전화/문자, 웹 검색, 음원 재생은 하지 않습니다.
- 갤러리에는 샘플 이모지 이미지가 들어 있습니다.
- 메시지 대본은 `index.html`의 `people` 데이터에서 수정할 수 있습니다.
- 외부 API, 서버, 데이터베이스를 사용하지 않습니다.
