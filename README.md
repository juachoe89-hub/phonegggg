# Character Phone

가상 캐릭터 휴대폰 웹사이트입니다.

## 실행
- `index.html`을 브라우저에서 열면 실행됩니다.
- GitHub Pages에 올릴 경우 `index.html`을 저장소 루트에 두고 Pages를 활성화하세요.

## 포함 기능
- 4자리 숫자 암호 잠금(아무 숫자 조합 가능)
- 사진, 캘린더, 메모, 시계, 음악, 전화, 연락처, 메시지, 인터넷
- 무지창/삿가심/금시완의 초기 대화 기록과 미리 작성된 답장 대본
- 첫 실행 시 무지창 알림, 5초 뒤 금시완 알림
- 앱 화면에서 좌우 스와이프로 뒤로 가기
- 새로고침하면 플레이어가 보낸 메시지 등 임시 데이터 초기화

## 참고
아이콘은 Apple 앱 아이콘 스타일을 참고해 웹용으로 재현한 것입니다. 실제 iOS 앱이나 실제 전화·문자 기능은 아닙니다.
